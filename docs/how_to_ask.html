受付への頼み方

2026-09-21総合受付 (sougou)

~/sougou で Claude を開いたあと、何をどう頼むか。 結論から言うと普通に話しかけるだけですが、その裏で何が起きているかを知っておくと、 通る依頼と空回りする依頼の差がわかります。

先に結論

1. 頼み方は普通の日本語でいい。どの door へ渡すかは受付が決めるので、door 名を覚える必要はない。

2. ただし door は毎回まっさらで立ち上がる。前回の話を覚えていないので、必要な文脈は依頼に書く。

3. 受付は実作業をしない。「research のファイルを直して」と言うと、受付ではなく door に渡される。

1. あなたの言葉が流れる道

cd ~/sougou && claude で開いて話しかけると、こう流れます。 あなたが触るのは①だけで、②③④は受付がやります。

foyer ask を自分で打つこともできますが、普段は不要です。 受付に「動画の素材で翼竜のベース画像あったっけ」と言えば、受付が paleo-video に聞きに行きます。

2. どこへ行くかは中身で決まる

受付は CLAUDE.md の表だけを見て振り分けます。行き先は 3 つです。

迷ったら振り分けを考えなくて大丈夫です。 受付の仕事が「どこへ渡すかを決めること」なので、そのまま言えば判断します。 行き先を指定したいときだけ「llm-wiki に聞いて」のように名前を出せば従います。

3. door は毎回まっさらで立ち上がる

ここが一番の落とし穴です。door への依頼は 1 回 = 1 ターンで、 前の依頼を覚えていません。同じ door に 2 回聞いても、2 回目は初対面です。

実際の運用では、あなたが -s を意識する必要はありません。 「さっきの続きで、もう少し深く」と言えば受付が繋ぎます。 知っておくべきなのは 1 回の依頼文で話が閉じている方が精度が高いということだけです。

依頼文の良し悪し

空回りしやすい

「task-decomposer どう思う？」

通りやすい

「task-decomposer が .claude/agents と .claude/commands のどこからも名指しされていない。 /new-episode から台本生成までの動線で、タスク分解は誰がどうやっている？ 実際のファイルを読んで答えて」

違いは 3 点です。いま分かっている事実を置き、答えてほしい問いを 1 つに絞り、 根拠の取り方（実ファイルを読む）を指定している。 door は初対面なので、この 3 つが揃うと一発で返ってきます。

4. 実例 — 今回の依頼がどう流れたか

段階起きたこと
あなた「task-decomposer が要るのか判らない。消す前に確かめたい」
受付調べる対象が research の中 → paleo-video へ渡すと判断
door 1 回目「配線は無い。ただし paleo-writer が素通りしている」
受付これだと「配線すべき」とも読める → 問いを立て直す
door 2 回目「配線しても増えるものは何も無い」と言い切った
受付退役候補に倒し、棚卸表を更新。判断を llm-wiki に記録

door を 2 回叩いたのが要点です。 1 回目の答えは両方に読めたので、2 回目で「配線したら今より何が増えるか」に問いを絞りました。 あなたは 1 回頼んだだけで、この往復は受付がやっています。

5. やらないこと

やらないなぜ
受付でよその repo を直接編集する受付は取り次ぎ役。実作業は door の向こう
CLAUDE.md に知識や手順を足すdoor が増えても行数を増やさない。1 door = 表の 1 行
回・案件ごとに door を作るdoor は用途に 1 つ。回の状態は向こうが持つ
依頼文に API キーや .env の中身を書くdoor 越しに渡り、記録にも残る
読めば分かる事実だけを llm-wiki に入れる判断・実測・文脈・失敗のどれかが要る

どれも受付が守るので、あなたが気にする必要があるのは 認証情報を書かないの 1 点だけです。

6. 詰まったとき

症状どうなっているか
「busy なので後で」と言われるその door で別のセッションが動いている。待たずに後で頼む仕様
permission denied が出るdoor の allowlist の話 → docs/door_permissions.html
foyer が無い・door が空新しいマシンかコンテナ。bash scripts/setup.sh で入れ直す
答えが的外れ依頼文に前提が足りない可能性。§3 の 3 点を足して言い直す

受付そのものの導入や不調は docs/setup.md が正本です。
