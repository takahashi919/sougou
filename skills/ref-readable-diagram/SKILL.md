# ref-readable-diagram

説明図 (フロー・構成図・状態遷移・シーケンス) の**解読速度** — 初見の読者の頭に構造がどれだけ速く入るか — の本質原則辞書。データ可視化 (チャート・グラフ) は対象外。

**核心の言語化**: 「見やすさ」は **解読速度** (構造がどれだけ速く頭に入るか) と **品位** (制作物としての整い) の 2 軸に割れる。品位のための抑制 (色を消す・重複を消す) は解読速度と対立し得る。本 ref は解読速度側の正本 — 「洗練されて見える」を根拠にスタイルを選んではならない。

## 目的関数

初見の読者が、文字を読み始める前に構造 (何種類あるか / どこから読むか / どこへ繋がるか / いくつの束か) を見分けられ、文字は確認のためだけに使えば済む説明図を作る。

## 原則

各原則に **逆の失敗** / **非還元性** / **領域転移** (フロー以外の図種での読み替え) / **既知概念との対応** を併記する。既知概念は「同じことを別語彙で言っているものの照合」であり、権威の根拠ではない。

### P-1 色は「意味の識別」に割り当てる (識別ファースト)

色の第一の職務は装飾でも雰囲気でもなく識別 — 登場人物・レーン・状態・線の意味を「読む前に見分けられる」ようにする。色数は意味の種類数までで、余った色は使わない。**既定は識別ファースト**。**例外は 1 条件のみ**: 一本道 × 登場人物 2 以下の図に限り、抑えた単色 + 焦点 1 点へ切替可。

- **逆の失敗**: 色を装飾に使うと「何種類あるか」の判定が文字読みに落ち、図が一瞥の対象でなく読む対象になる。
- **非還元性**: P-2 (冗長) は「同じ区別を何チャネルに重ねるか」を問い、本項は「色というチャネルに何の職務を与えるか」を問う。色だけで識別する図 (P-1 ○ / P-2 ×) も、番号と囲いだけの無彩色図 (P-1 × / P-2 ○) も現実に存在するので独立。
- **領域転移**: フロー = 実行主体 / 構成図 = 部品の種別・所有者 / 状態遷移 = 状態のクラス (正常・異常・終端) / シーケンス = レーンの主体。
- **既知概念との対応**: 前注意的処理 (色は読む前に処理される) / 選択的視覚変数 (色相は「同じか違うか」を一瞥で返すチャネル)。

### P-2 同じ区別を 2 つ以上のチャネルに重ねる (冗長コーディング)

同じ構造を色 + 番号 + 囲い (+ アイコン) で重ねて伝える。エレガンスは重複を嫌うが、重複はチャネル喪失に確実に強く、識別の取りこぼしを防ぐ (判別速度の利得は条件付き — 下の対応概念)。ただし重ねる先は**非文字チャネル**であり、文章の反復で冗長を取ってはならない (それは P-4 違反)。

- **逆の失敗**: 1 チャネルに一意化すると、そのチャネルが落ちた瞬間 (白黒印刷・縮小表示・色覚差・スクショの劣化) に構造がまるごと消える。
- **非還元性**: P-1 は職務の割当、本項はチャネルの本数。P-4 との境界も本項が引く (冗長は色・番号・囲い・アイコンで取り、文字では取らない)。
- **領域転移**: 構成図 = レイヤ色 + 枠線 + 位置 / 状態遷移 = 状態色 + 形 (角丸・二重線) / シーケンス = レーン色 + 見出し。
- **既知概念との対応**: 冗長符号化 (redundancy gain)。**確実な効果はチャネル喪失への頑健性** (白黒印刷・縮小・色覚差でも構造が残る)。判別速度の利得は条件付き (視覚探索では最も識別しやすいチャネルが律速) — 普遍の速度向上は主張しない。**注意**: 教材設計でいう「冗長性は害」は *同じ内容を文と音声で二重に読ませる* 場合の話で、本項の非文字チャネル重畳とは別命題。

### P-3 初期注視点と探索規則を一意にする (読み順)

図には「最初に見る場所」が 1 つあり、「次にどこを見るか」の規則が形で示される。目の迷子を作らない。順序が本質でない図 (非階層のネットワーク等) でも、初期注視点 (視覚的重みで立てた起点) と探索規則 (例: 中心から外へ) は与えられる。

- **逆の失敗**: 初期注視点が複数解釈できると、読者ごとに違う順で読み、同じ図から違う理解が出る (図が合意形成に使えなくなる)。
- **非還元性**: P-6 (線の追跡) は「1 本の線がどこへ繋がるか」の幾何、本項は「全体をどの順に見るか」の順序。入口が明快でも線が交錯する図、交差ゼロでも入口が分からない図はどちらも成立する。
- **領域転移**: フロー / シーケンス = ①②③ の番号チップ + 一方向の矢印 / 構成図 (階層あり) = 上下または左右の階層と包含 (上位から下位へ) / 構成図 (非階層ネットワーク) = 視覚的重み (サイズ・位置・色) で起点ノードを 1 つ立てる / 状態遷移 = 初期状態マーカーと矢頭 (循環は「循環と分かる形」に閉じる)。
- **既知概念との対応**: 合図づけ (signaling — 見るべき順序を明示的な標識で誘導する) / 誘導された注意。

### P-4 文字は節度 (図を文章に退行させない)

図の要素 (箱・ノード・レーン見出し) の中は 2 行まで (名詞句 + 短い補足)。図の外の説明はサブタイトル 1 つまで。散文の補助パネル (「図の見かた」等) は置かない。ただし**アイコン・SVG 図像は文字と別勘定で歓迎**する。矢印や要素への因果注記は 25〜40 字までなら本項の節度内に収まる。本項の管轄は**文字の密度**のみ — 凡例 (記号の対応表) の扱いは P-7 の管轄。

- **逆の失敗**: 要素に説明文を積むと、全部読まないと意味を成さない図になる — 図が文章の挿絵に退行し、図を置いた理由そのものが消える。
- **非還元性**: 色・読み順・束ねをすべて満たしたまま文字量だけで遅くなる図は普通に存在する。文字量は他の 6 原則のどれにも吸収されない独立量。
- **領域転移**: 構成図 = コンポーネント名 + 一言の役割 / 状態遷移 = 状態名 + 遷移条件の短句 / シーケンス = メッセージ名のみ (引数の羅列は落とす)。
- **既知概念との対応**: 図の計算的優位性 (同じ情報でも図は探索コストが低い — その優位は文字を積むほど失われる) / 図と文の相補統合。

### P-5 見出し付きの区画で束ねる (チャンク化)

要素が 6 を超えたら、見出しの付いた区画で 3〜4 群に束ねる。**フロー図ではフェーズ帯 (「依頼を出す / 実行する / 受け取る」) が既定の型** (外すなら作り手が理由を持つ)。

- **逆の失敗**: 束ねずフラットに並べると、部分は読めるのに「で、全体は何をしているのか」に答えられない図になる (全体像が作業記憶に載らない)。
- **非還元性**: P-3 は順序、本項は階層。番号が完璧に振られた 12 ステップの一列図は P-3 ○ / P-5 × で、実際に読めない。
- **領域転移**: フロー = フェーズ帯 / 構成図 = レイヤ・境界 (外部 / 自システム / 保存先) / 状態遷移 = 上位状態でのグルーピング / シーケンス = 縦方向のフェーズ区切り。
- **既知概念との対応**: チャンク化 (作業記憶に同時に載るのは 4±1 の塊) / 共通領域 (囲いは近接より強くグループを作る)。

### P-6 線は端まで目で追える形にする

接続線は交差・迂回・分岐の集中を避け、「この線がどこへ着地するか」を指でなぞらずに追えるようにする。追えなくなったら線を減らすか、図を割る。

- **逆の失敗**: 線が交錯すると、読者は隣の線に乗り換えて誤読する — しかも本人は誤読に気づかない (色も番号も正しいまま結論だけ間違う、最も危険な壊れ方)。
- **非還元性**: P-1 (色)・P-2 (冗長)・P-4 (文字量)・P-5 (束ね) をすべて満たした図でも、線が 20 本交差すれば接続の追跡だけで時間が溶ける。要素の設計 (他原則) と接続の幾何 (本項) は別レイヤ。
- **領域転移**: 構成図 = 依存線の交差 / 状態遷移 = 遷移矢印の輻輳 / シーケンス = レーンをまたぐ長距離メッセージ / フロー = 戻り線の引き回し。
- **既知概念との対応**: グラフ描画の交差最小化 (交差数は読み取り正答率に効く代表的な指標) / 階層レイアウト (流れの向きを揃えると交差が減る)。

### P-7 記号の語彙は凡例なしで持てる量に収める

線種は 2 まで。凡例を置くこと自体は可 (確認用の保険) だが、凡例を都度見ないと読めない図は記号が多すぎる — 線種を減らすか図を割る。

- **逆の失敗**: 線種が 3 以上になると本体と凡例の往復が始まり、往復のたびに読みかけの文脈を失う (凡例が読解の律速になる)。
- **非還元性**: P-2 (冗長) はチャネルを**増やす**方向、本項は 1 チャネル内の**語彙数**を絞る方向。増やすチャネルと絞る語彙は別の量で、両立する (色 3 種 × 線種 2 種は成立、線種 5 種は色を足しても救えない)。
- **領域転移**: 構成図 = 実線 (同期) / 破線 (非同期) までで、太さ・色・矢頭に第 3 の意味を載せない / 状態遷移 = 通常遷移と例外遷移の 2 種 / シーケンス = 要求と応答の 2 種。
- **既知概念との対応**: 分割注意 (本体と凡例に情報が分かれると統合コストが発生する) / 外的記憶への依存。

## 適用限界

- 本原則は「解読の速さ (どちらが見やすいか)」の判断基準であり、読者の理解度を測る基準ではない。
- データ可視化 (チャート・グラフ) は対象外。対象は構造の説明図 (フロー・構成・状態遷移・シーケンス)。
